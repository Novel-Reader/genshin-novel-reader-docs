# 阅读器功能说明

## 离线模式

核心功能是纯文本小说阅读，包括上传小说、按章节或分页阅读，以及自定义阅读界面样式（文字颜色、字重、整体色调和背景色等）。阅读器还提供多种卡通背景图片。

整体界面采用左、中、右三栏布局：

左侧导航栏：支持本地上传或在线搜索小说，并以列表形式展示；另一个标签页以树状结构展示章节。

中间阅读栏：提供整页、分页和全屏等阅读模式。

右侧设置栏：可在基本设置和高级设置之间切换。

![](../screenshots/0.7-06.png)

## 在线模式

在离线模式的基础上，1.0 版本增加了用户登录、注册和后台管理等功能，以及在线搜索、下载和上传小说等操作。
