# 用户权限

## 本地模式

`offline`：离线模式，显示“欢迎使用本地模式”等提示。

网络不可用时，或用户选择以游客身份使用应用时，可切换到离线模式。此时权限标识为 `offline`。

## 在线模式

### 已登录用户：免费版 `free`

### 已登录用户：付费版 `vip`

前端可根据 `offline`、`free`、`vip` 或 `admin` 等权限状态控制界面展示。权限状态可以保存在应用状态中，但涉及数据访问和管理操作的权限必须由服务端验证，不能只依赖前端判断。

| 字段    | 网络状态 | 登录状态 | 本地上传 | 小说数量 | 在线查询 | 高级设置 | 用户管理 |
| ------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| offline | 断网     | 未登录   | √        | 3        | x        | x        | x        |
| free    | 联网     | 已登录   | √        | 10       | x        | x        | x        |
| vip     | 联网     | 已登录   | √        | 100      | √        | √        | x        |
| admin   | 联网     | 已登录   | √        | 不限     | √        | √        | √        |

### admin 账户

管理员通过服务端鉴权访问管理功能，可批量管理小说和用户。管理员 API 应单独设计并实施服务端权限校验；不要仅通过隐藏前端入口保护接口。
