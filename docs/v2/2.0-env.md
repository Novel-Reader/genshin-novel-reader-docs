## 环境配置和工具

### 前端开发

简易开发只启动前端项目，适合调试离线模式，不需要启动后端服务。

需要安装 Node.js、Git 和浏览器。克隆项目后，在项目目录中执行：

```bash
git clone https://github.com/Novel-Reader/Genshin-novel-reader.git

cd Genshin-novel-reader

npm install

npm start
```

执行 `npm start` 后，开发服务器通常会自动打开浏览器；如果没有自动打开，可访问终端输出的本地地址。

### 全栈开发

全栈开发用于调试在线模式，支持前端与后端服务通信。

需要安装 Node.js、Git、Docker、Postman 和浏览器等工具。若项目脚本未自动重启服务，还需要安装 nodemon。

1、选择一个干净的开发目录，拉取代码

```bash
git clone https://github.com/Novel-Reader/Genshin-novel-reader.git
git clone https://github.com/Novel-Reader/Genshin-novel-reader-express-server.git
```

2. 创建数据目录：在后端项目中创建 `mysql-data` 文件夹，用于持久化 MySQL 数据。

```bash
cd Genshin-novel-reader-express-server
mkdir -p mysql-data
```

3. 检查 `docker-compose.yml`：将 MySQL 数据卷配置为本地路径。以下为路径映射示例，实际应按 compose 文件的卷语法填写：

```bash
./mysql-data:/var/lib/mysql
```

4. 启动数据库容器，并连接 MySQL：

```bash
docker-compose up
docker exec -it novel-mysql bash
mysql -u root -p
# docker-compose up 中配置了环境变量：MYSQL_ROOT_PASSWORD=db_dev
```

5. 初始化数据库：

```sql
create database novel charset utf8mb4;
```

6. 创建数据库表：执行后端项目 `upgrade/sql` 目录中的建表语句。

7. 启动 Node.js 后端服务：

```bash
cd Genshin-novel-reader-express-server
npm install
npm start
```

8. 按客户端项目的实际配置，将运行模式切换为在线模式。以下仅为配置值示例：

```
mode: offline
改成
mode: online
```

9. 启动前端客户端：

```bash
cd Genshin-novel-reader
npm install
npm start
```
