## 总结

2023 年春节前后开始构思项目，并在春节期间完成主要框架和前端功能；随后补充了后端基础能力，形成了可用的小说阅读器。此后项目继续迭代，并在 2024 至 2025 年完成 2.0 阶段的主要工作。

通过这个项目，我在实现阅读器基本功能的基础上，逐步增加了小说上传和下载、用户注册与登录验证、JWT 等能力，也实践了较完整的项目流程：

- 分析需求，调研竞品特点，完成产品文档
- 完成基本原型图和设计稿
- 前端技术选型，搭建项目，完成细节交互
- 后端技术选型，搭建基本服务
- 数据库技术选型，完成 API 通信和验证
- 本地测试和在线测试，并逐步迭代整个过程

这个项目也暴露出一些不足：部分基础知识掌握不够牢固，需要查阅文档；设计预期与最终实现之间也存在差距，因此仍需补充 UI 设计等方面的知识。

后续将以维护现有功能为主，并视实际需要改进工程化和技术实现。
