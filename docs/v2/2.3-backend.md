## 后端技术点

### 服务器

后端基于 Express 提供 REST API。该项目主要面向个人使用和功能实践，不以高并发或负载均衡为设计目标。

### 第三方库

- `body-parser`：解析 JSON、Raw、Text 和 URL 编码的请求体。
- `cookie-parser`：解析请求中的 Cookie，并通过 `req.cookies` 提供访问接口。
- `multer`：处理 `multipart/form-data` 请求，常用于文件上传。
- `log4js`：日志记录工具。
- `jsonwebtoken`：创建和验证 JWT 的工具库。
- `express-jwt`：在 Express 中间件中验证 JWT。
